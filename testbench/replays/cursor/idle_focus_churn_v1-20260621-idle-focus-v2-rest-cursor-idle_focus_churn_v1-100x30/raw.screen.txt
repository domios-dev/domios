  A blinking cursor only means the terminal is redrawing a caret on an idle prompt or input
  line—it is a local UI animation, not a heartbeat from the agent. The model may be thinking,
  waiting on a tool, blocked on network I/O, or finished while the shell still looks “alive,”
  and conversely the cursor can blink even when nothing useful is happening. Treating cursor
