  A blinking cursor is just a UI animation on a timer — it keeps pulsing whether the agent is
  computing, waiting on a blocked call, stuck in a loop, or sitting completely idle at a prompt. It
  reflects the terminal's render state, not the process's actual progress, so it can blink
  identically during heavy work and during total inactivity. Real evidence of work is concrete
  output: files changed, tests run, logs emitted, exit codes, or measurable state transitions — not
  the mere fact that something on screen is moving.
