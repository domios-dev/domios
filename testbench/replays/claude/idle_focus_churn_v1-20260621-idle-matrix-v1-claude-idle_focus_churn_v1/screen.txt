⏺ Wrote idle-notes.md.
  A blinking cursor only proves that a process is alive and waiting for input — it's an idle state, not evidence of
  work. An agent can sit on a blinking prompt having done nothing, while real work shows up as concrete artifacts: files
  changed, commands run with output, tests passing, commits made. The cursor reflects the terminal's readiness loop,
  which keeps ticking whether or not anything meaningful is happening behind it. To know an agent actually did
  something, look at what it produced, not at the fact that it's still blinking.
