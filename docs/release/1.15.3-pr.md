# Domios 1.15.3

## Release notes

- Account Mesh now connects machines through receiving-machine approval. My machines shows account membership, connection state and machine names, with renames reaching connected peers.
- Sign out this machine revokes its installation session and closes remote access. Remove and sign out manages another machine explicitly; removed machines can sign in and rejoin through fresh approval. Signed-out, offline and plan-limited machines keep distinct states and appropriate actions.
- Private network setup explains Tailscale state and network identity. Signed-in machines publish health-proven peer endpoints, track address changes and close listeners on sign-out. The machine switcher keeps local and remote work clear.
- First run carries provider installation and sign-in through to General. General receives its greeting and supplied startup context as its first input, and account sign-in survives an initiating UI disconnect.
- Blueprints add typed inputs, multiple data ports, reusable saved solutions, controlled tags and nested graph navigation. Live journals and bounded value previews expose execution state; graph checks make invalid work visible before execution.
- Agent conversations handle restored first sends, missing sessions, runtime disconnects, provider changes, attachments and background completion more reliably. Uncertain input is never replayed automatically.
- Memory recall stays responsive during background re-embedding, with queue progress and failures visible. Navigation, paged chat history, mobile scrolling, tool cards, plan limits and plugin update cleanup receive fixes.
