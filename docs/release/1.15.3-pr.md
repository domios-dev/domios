# Domios 1.15.3 release draft

Status: preparation only; no publication authorized. This is a notes draft from merged work since `v1.15.2`, reviewed through candidate `977e74c31cf2b3073244083a69b334010a779ced`. Refresh it against the final reviewed SHA before shipping.

## Release notes draft

- Blueprints gain typed graph inputs, multiple data ports, reusable saved solutions, controlled tags and nested graph navigation. The shared viewer shows live run journals and bounded value previews; checking and quarantine make invalid graphs visible before execution.
- Account Mesh lists signed-in machines, uses receiving-machine approval for new connections and exposes clear signed-out and disconnected states. Machines publish health-proven endpoints on Tailscale addresses, follow address changes and close remote listeners on sign-out. Machine names and renames propagate to connected peers.
- Agent conversations recover more clearly from missing sessions and failed runtime channels. Restored first sends, provider switching, background task completion and attachment handling receive reliability fixes without replaying uncertain input.
- Memory startup and embedder changes keep recall responsive while re-embedding proceeds in the background. Embedding queue state, failures and recall priority are visible.
- Account plans, Team limits and locked work use shared enforcement and clearer account/plan presentation. Legal texts and in-app links are included.
- Navigation restoration, paged chat history, mobile scrolling, tool cards and Blueprint reading views receive usability fixes.
- Plugin updates preserve active runtimes and clean staged files. Secret lookup and errors receive additional containment and redaction checks.

These are merged-source descriptions, not a claim that final DEV QA or release qualification passed. Per-installation sign-out and Ease's remaining client work must be reconciled into the final notes after integration. Issue-closing metadata must be generated through the release issue contract; this draft declares no issues closed.
