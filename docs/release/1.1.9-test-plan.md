### F. Socket JSON-RPC (socket/server prefix-routed dispatch)

Hit each domain prefix to verify routing:

```bash
PORT=7686 TOK=$(jq -r .api_port ~/.codeterm-dev/config.toml || awk -F'"' '/token/{print $2}' ~/.codeterm-dev/config.toml)
# substitute real token:
TOK=$(awk -F'"' '/^token/{print $2}' ~/.codeterm-dev/config.toml)
curl -s -X POST localhost:$PORT/rpc -H "Authorization: Bearer $TOK" \
  -d '{"method":"workspace.list","id":1}'    # workspace.* domain
curl -s -X POST localhost:$PORT/rpc -H "Authorization: Bearer $TOK" \
  -d '{"method":"pane.list","id":1}'         # pane.* domain
curl -s -X POST localhost:$PORT/rpc -H "Authorization: Bearer $TOK" \
  -d '{"method":"notification.list","id":1}' # notification.*

  -d '{"method":"cron.list","id":1}'         # cron.*

  -d '{"method":"bridge.status","id":1}'     # bridge.*

### J. Mesh disconnect/reconnect (THE hard test)

```
BLACKSTAR (in parallel via mesh send-text from prod):
```bash

```

Reconnect:
```bash
# Mac initiates (Tailscale IPs we already know)

```

- [ ] After disconnect, `mesh peers` no longer lists the other dev side
- [ ] After re-connect + approve, both `mesh peers` show the partner again
