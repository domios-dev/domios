## CodeTerm 1.14.0

Plan `pl_a0rcq7`. 1.14.0 ships everything that was staged as 1.12.4 together with the storage, chat and Blueprint work that followed it. The version jump marks the size of the release; there is no 1.12.4 or 1.13.x build.

### Providers
- Codex structured lane: a per-tab app-server sidecar, remote TUI attach, streamed transcript, structured approvals, and RPC sends with exact delivery evidence. Busy messages are held and sent as one next turn. New tabs open instantly. `agents.codex.structured_control_enabled = false` restores the plain PTY lane.
- Claude: permission requests answered from Domios notifications, a context meter, thinking summaries, a model capability manifest, fork, and per-launch settings files.
- OpenCode provider stack with a streamed channel, structured file diffs, exact-session restore, and a declared compatibility with OpenCode 1.18.35.
- Tool-less providers (the Aider plugin) with reply relay and managed tabs.
- A status-line model and effort picker. Codex applies on the next turn, OpenCode live, and Claude through restart and resume.
- Close and Undo restore the exact session together with its model and effort overrides. Sends made before a launch authenticates are queued and delivered once.

### Chat
- Live chat blocks: `@ds-plugin`, `@ds-guide`, `@ds-choice`, `@ds-agent`, `@ds-job`, `@ds-checklist`, `@ds-tasks`, `@ds-connect` and `@ds-setting`, on one shared frame. The catalogue is `codeterm docs CHAT-BLOCKS`.
- Message actions from a quiet gutter dot, with part-level targeting of long answers ("This part | Whole message"), Telegram-style quote replies, block selection by drag, and a long-press sheet on touch.
- Rich composer attachments use one `<domios type="attachment">` tag family.
- A Documents and Changes side panel per tab, with a Diff | File view, fullscreen, and changed-file counts.
- General Agent helper moments suggest an unused feature when it fits what the user is doing.
- All transient notices share one stack under the bell, with a countdown ring, a 15 s cap, and the bell as their history.

### Blueprints
- Typed Trigger, Source, Agent and Action graph view, with replayable runs, liquid motion, and explicit stop and error endpoints.
- Pipeline Blueprints reach the UI through one contract; closed runs read as idle; pattern decisions are labelled as pattern rules.
- `codeterm blueprint export | import` with a portable `.blueprint.json` built on recipe placeholders, plus Export and Import in the UI.
- `codeterm blueprint delete`, and shell-created Blueprints are visible in Jobs.

### Teams, storage and restore
- Typed SQLite storage for the desk, durable Team and workspace close inventories, and Recently Closed restore with stopped utility shells.
- Utility shells with a declared purpose, live running state, and slot reuse.
- Shell profiles with discovery, including WSL.

### Plugins and settings
- Plugin pages hold harness settings; the Integrations tab is gone, and Telegram lives in General > Messengers.
- Core plugins at bare channel paths stay verified after a channel update.

### Known limits, moved to 1.14.1
- A send made at the exact moment a tab restores or relaunches is refused honestly and nothing is written; queueing it is 1.14.1 work.
- Claude in-place model switching through `/model` is implemented but not armed; Claude switches by restart and resume.
- Codex actual effort after a restore can read "unverified" until the provider reports it again.
- Fresh General Agent sessions from the sidebar are hidden until they have their own launch contract.
- The Grok plugin readiness fix ships with the plugin channel.

### Verification
- A live QA matrix across Codex, Claude chat and PTY, OpenCode, Aider, Grok, shell, General Agent and Team restore, rerun on four release candidates.
- The full gate on the release head: `./build.sh verify` (6104 of 6106 passed; the two Windows probe timing tests pass when run alone), 608 TS unit files, vitest, and 46 plugin suites, plus the tests.yml matrix on this PR.
