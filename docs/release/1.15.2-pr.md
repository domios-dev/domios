# Domios 1.15.2

Release candidate: `develop` f1de62124, branched to `release/1.15.2` with the version bump.
Publication, tags and promotion need the owner's GO.

## The app becomes Domios

- The installed application is Domios: product name `Domios`, identifier `com.domios.app`, GUI
  executable `domios-app`. The packaged CLI ships as `domios` and `codeterm` from identical bytes;
  `domios` is the primary command in help, docs and prompts.
- This is a manual move. CodeTerm 1.15.1 cannot update itself into Domios: install Domios fresh,
  then remove the old app. Per-OS steps are below. Data stays in `~/.domios`; nothing is migrated.
- New clients read only `domios-latest*.json`. The old `latest*.json` channels now carry the manual
  move notes with no platform payloads: a 1.15.1 client reports the release as incompatible, and a
  forced install fails before any download or server shutdown.

## What changes for you

- Plans are stored as relational task, milestone and attempt rows with an incremental recall index;
  deleting a plan never waits for indexing, and deleted plans leave every index (P0, forward-only
  schema).
- Curator rounds run in a visible read-only tab under the team manager, render system deliveries and
  timeline events, and can be finished by hand.
- Blueprint runs receive bounded previous results on stdin, run without instance credentials, and
  Blueprint recall uses vectors with a relevance floor.
- The composer has scoped mention sources with a caret-aware picker, live-scope mention chips and
  grouped background subagents.
- Chat copies attachments as complete files, shows their names, shares fullscreen camera, supports
  image galleries and keeps the transcript following the session after tab switches.
- Agent input is framed: routed reports and large messages arrive as one paste, typed inputs reconcile
  across transports.
- Mesh artifacts enforce the private-path policy for outgoing files.
- Lane worktrees clean themselves up completely when their work lands.
- Billing signs you in at purchase; plans stay browsable and checkout opens in the app's theme.
- Product analytics deliver with consent in production.

## Fixes

- Team close, plan delete and slow plan deletion no longer hang; Workers report their Team on spawn.
- Tab restart delivers its input; restored tabs wake on transcript changes.
- Startup recovers stale sockets, rewrites relocated stored paths under the legacy data root and
  reports stale root references.
- Updates scrub the relaunch environment, verify Debian staging, explain privileged Debian updates
  and recover interrupted updater handoffs.
- The sidebar keeps visible rows in place when lists shrink.
- Worker checklist review cards stay out of the parent chat; report task chips and references render.
- Bundled plugins ship only runtime files.
- Shipped prompts no longer carry repository procedures; remaining CodeTerm naming in docs, help and
  health is gone.

## Removed

- The retired 1.14.9 upgrade path and its J5 gate.
