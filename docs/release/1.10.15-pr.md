# Release 1.10.15

Plan: `pl_lqag3i` — post-cutover launch, restore, reporting, and provider discovery repairs.

## Changes

- Fix Codex Windows launches failing with invalid TOML: serialize plain instruction text instead of PowerShell filesystem metadata.
- Keep Codex session ownership separate from shared transcript lookup so another provider cannot claim the same cached record.
- Apply both approval/sandbox and hook-trust bypass flags only when Full access is selected, for new and resumed Codex sessions.
- Resolve an omitted Planner parent from its Plan owner before synchronous tab provisioning.
- Make accumulated review WIP/credit pressure advisory while preserving ownership, dependency, and task-transition checks.
- Recover a missing restored provider only from unique ownership of the exact saved session, with lifecycle/PTY identity guards.
- Scope whole-peer Web terminal streams with composite tab identity and preserve standalone boot cursors across reconnects.
- Render Codex CommandExecution and SubAgentActivity completions, including real argv-array commands, without collapsing mixed command batches into a single help card.
- Resolve an absent task-less reporter session from its exact hook-attested tab binding while retaining owner-issued grants and all foreign/stale/task-mutation refusals.
- Detect and preserve relocated local-installer Cargo caches before regeneration instead of compiling against deleted absolute Tauri permission paths.
