# Naming Research — CodeTerm Rebrand

**Status:** Research complete, decision pending  
**Date:** 2026-04-05

## Context

CodeTerm has outgrown its name — it's not a "code terminal" anymore, it's a distributed OS for AI agents. Looking for something cyberpunk/exocortex-flavored that reflects the vision: agents as extensions of the developer's mind, mesh as neural fabric.

## Available Names (verified clean)

| Name | Vibe | CLI feel | Notes |
|------|------|----------|-------|
| **Ahive** | Cyber-hive, agent swarm | `ahive agent spawn` | .io/.dev likely free, npm free, no software conflicts. "A hive" = the hive. Short (5 chars). Mesh = hive nodes, hierarchy = swarm roles. |
| **Synkort** | Synapse + cortex, neuroimplant | `synkort agent spawn` | Zero conflicts anywhere. Sounds like a Deus Ex implant. 7 chars. |
| **Cortika** | Cortex + suffix, biotech implant | `cortika mesh peers` | No exact conflicts. "Cortica" (AI company) exists but different name. Soft, brandable. 7 chars. |
| **Hivecort** | Hive + cortex, swarm-brain | `hivecort pane split` | Zero conflicts. Combines collective intelligence (hive) with neural (cortex). 8 chars — slightly long. |
| **Colony** | Agent colony, distributed organisms | `colony mesh peers` | Only niche conflicts (mouse colony mgmt, UK allotments). Simple, clear metaphor. 6 chars. |

## Evaluation Criteria

- **CLI ergonomics** — short, easy to type, no ambiguity
- **Metaphor fit** — matches distributed OS / agent swarm / neural extension vision
- **Trademark clean** — no software/AI/tech conflicts
- **Domain availability** — .dev or .io preferred
- **Cyberpunk feel** — not corporate, not generic
