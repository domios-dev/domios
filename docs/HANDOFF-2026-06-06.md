## Working protocol used for this batch (keep using it)

Andrey's mandate: every task runs as an autonomous pipeline — **Spec → Plan → Gap/Risk analysis → Implement → Verify** — optimizing for SOLID/DRY, minimal hardcode, maintainability, and above all "do no harm". How that played out here, so the next agent can replicate:

1. **Spec first.** One paragraph: desired behavior + acceptance criteria. (T2: "`--mesh` must behave identically to local; unroutable commands must error honestly, not fake success.")
2. **Plan against the source of truth.** Find the canonical schema/contract before writing code (T2: both transports deserialize into `CronCreateParams` → therefore ONE shared body builder, not two patched copies).
3. **Gap/Risk before touching anything.** What breaks, who else writes here, is it reversible? Subagent (Explore) fan-out is fine for *mapping*, but **verify every load-bearing claim yourself by reading the code** — the Explore pass on T1 mis-identified the crash site (test-only mirror vs production worker); a fix built on it would have missed the bug. Same lesson earlier: a relayed finding ("mem worker spawn not implemented") was simply wrong.
4. **Prefer structural fixes over patches.** Shared predicate/builder/const instead of duplicated logic (NOT-EXISTS guard shared by COUNT+UPDATE; `cron_create_body()`; `UNSUPPORTED_OVER_MESH` const instead of a magic string).
5. **Honest errors beat silent fallbacks.** The old "return /stats so the caller gets valid JSON" pattern reads as success and corrupts downstream agent behavior.
6. **Every fix ships with a regression test that encodes the bug** — and delete old tests that encoded the wrong behavior (one asserted the /stats mis-mapping).
7. **Gates.** Read-only survey before any destructive op; live tests against prod state must restore it exactly (plugin-store e2e: add→install→verify→remove, registry byte-identical after); commits/pushes/schema-migrations/data-dedup only on Andrey's direct word. The #112 dedup-repair primitive was deliberately left as a *decision*, not done unilaterally.
8. **Worked examples** to copy: T1/T2 sections above; full claim-by-claim audit method in `docs/review-2026-05/prompt-gap-analysis-consolidated.md` (✓/✗/∆ per finding, 4 independent passes cross-checked).
