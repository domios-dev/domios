Done-heavy behavior is a first-class requirement across ALL views, not a Board footnote. A mature plan can have 200+ done tasks and ~10 active ones; the active ones must dominate every surface.

Requirements:
- Board: Done column bounded (recent N + count + in-column scroll after "show all").
- List: done rows quiet; fully-done sections collapsed to rollups by default.
- Canvas: done tasks aggregate into per-section done-stacks at normal zoom.
- Everywhere: total/done progress remains visible as numbers (header, column count, rollups) so completion still reads as progress, not hidden history.
- No view may produce unbounded page growth proportional to done-task count.
