The current planning UI is not pleasant or understandable enough for large real plans.

User evidence/screenshots:
- Board currently treats plan context as a small header and then drops into a board that feels disconnected from the plan/spec.
- Done-heavy plans can create an effectively infinite Done column/scroll; 200 done tasks should not make active work hard to read.
- Board and List do not make it easy to open a task and inspect details from the view.
- List feels structurally odd and does not solve the same inspectability problem.
- Canvas is currently the least stable/readable view at small zoom: it can lag, become tiny, and look confusing.
- Desired order and mental model: Board first, List second, Canvas third.
