Two recurring traps cost real time. (1) A worker that finishes but never commits, then has its worktree force-removed, loses everything — preserve before cleanup. (2) Symlinking node_modules into a worktree where an agent runs pnpm install corrupts the main node_modules into a self-referential symlink, breaking tsx repo-wide with exit 194 — give each worktree its own real node_modules and never commit node_modules. Both are now guarded.
