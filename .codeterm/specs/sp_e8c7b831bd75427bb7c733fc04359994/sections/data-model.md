A Plan nests Sections (a tree, each with markdown body), Tasks (name, type, model, model_rationale, status, status_label, section_ids many-to-many, body, milestones), and Milestones/Steps (kind, text, links, loop_id, iteration). Identity is stable across restart (session_id over pane_id). Every entity carries its own ElementCanvas position. Source of truth = per-project JSON at <project>/.codeterm/plans/<id>.json; an in-memory index enables fast cross-project listing; the daemon is the single writer (atomic temp-write + rename).
