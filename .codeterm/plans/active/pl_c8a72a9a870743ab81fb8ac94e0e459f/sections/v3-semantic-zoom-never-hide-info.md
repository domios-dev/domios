The canvas must NEVER hide information by zoom (today task cards drop body text at far zoom → empty boxes; unacceptable). All content is always present; zoom + node sizing make it readable. Far = legible overview; on approach = progressively more detail that ADDS, never removes. Approaches under evaluation: wider A4-ish nodes, text that scales with zoom (with a font floor), density swaps, internal columns/chunking so a detailed node never balloons into a kilometer-tall портянка that flies off-screen.
