---

Add a calm read-only view switch for plan work: Canvas remains the spatial overview; List shows the current Spec, Plan, tasks, and subtasks as a classic hierarchical execution list; Board shows read-only task columns while Spec and Plan remain visible as separate higher-level entities above the lanes. This is for watching agents work, not for user drag/drop editing.
