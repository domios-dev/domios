PLANNER AUDIT FINDINGS (round-103, full survey: 65 specs / 205 tests / 19 suites). THE GOOD (preserve, do not churn): suite organization is clean; title quality is mostly excellent — behavior + oracle in the title ('bad token is rejected with a rendered error, not a broken app', 'spawning into workspace B leaves NO husk in A', 'close is not idempotent-silent'); the best specs carry exemplary header doc-blocks (what/why/root-cause for regressions, testplan § references, quoted user complaints — see 16-chat-view/composer-focus-steal and most of 13-canvas); assertion density averages ~4.5 expects/test with real oracles (DOM order, round-trips, negative cases). THE GAPS, three concrete classes: (1) HEADERLESS SPECS (~10+ files have NO doc comment stating the test case): 16-chat-view/chat-rendering, 16-chat-view/chat-picker-default, 12-web/web-parity, 14-memory-ui/memory-panel, 19-web-stability/web-stability, 17-open-shell/lmstudio, 13-canvas/{canvas-perf-baseline,canvas-zoom-drift,workspace-plan-entry,_diag} — these are exactly the 'strange and unclear' ones; worse when combined with in-suite codenames ('RAIL-4 attention outranks working', 'GRP-4') that are only decodable if a header defines the taxonomy. FIX: every spec gets the header contract — 3-8 lines: WHAT is tested, WHY it exists (regression root-cause or feature contract), and the ORACLE in one sentence; codename taxonomies defined in the header that uses them. ENFORCE structurally: extend the comment-gate script family with a spec-header check (spec file without a leading doc-block fails the gate) — contract without enforcement rots, this plan proved it four times. (2) SLEEP-WAITS: 70 waitForTimeout occurrences across ~14 files (worst: 18-reorder/*, 16-chat-view/*, 12-web/tab-status-rail) — each is a flake seed and pads runtime; sweep to condition-based waits (expect.poll / waitForSelector / event assertions); allow a justified residue ONLY with an inline one-line reason. (3) WEAK ORACLES: 122 toBeVisible()/toBeTruthy() — many are legitimate step-gates, but audit each spec where a visibility check is the SOLE final assertion and strengthen to a behavioral oracle (content, state, round-trip). Deliverable: header contract landed + gate wired; waitForTimeout count 70 -> justified-residue only; sole-visibility-oracle list dispositioned; zero test semantics changed without a reason recorded.
