Planner recommendation for the variant set: Variant A (PRIMARY) = left-to-right assembly line — dispatch rail (compact) -> work floor (center, largest; one bay per lane, competing attempts = multiple avatars on one bay) -> QA bay + gate desk stacked right -> done shelf; parked/blocked side rail; orchestrator idles at gate desk, planner near HUD. Rightward motion = progress; QA fail animates task+avatar LEFT with a brief red pulse (the most informative animation in the system). Design thesis: unhealthy states must look physically wrong — empty work floor with non-empty dispatch reads as a hole (under-parallelization), swelling QA bay = bottleneck, idle worker on a bay dims to amber. Variant B = hub-and-spoke for honest contrast; Variant C = vertical compact for narrow windows. LOD: far = zone silhouettes + counts (departure board), mid = bays + avatars, close = full cards.
