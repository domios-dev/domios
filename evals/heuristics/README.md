# Heuristic boundary review

This directory contains the review inventory and verification procedures for moving classification decisions behind explicit authority boundaries. It has no standalone runner.

Start with [INVENTORY.md](INVENTORY.md), then follow the focused commands and expected evidence in [SLICE-1.md](SLICE-1.md), [SLICE-2.md](SLICE-2.md), or [SLICE-3.md](SLICE-3.md) for the affected boundary. [PASSIVE-CORRELATION.md](PASSIVE-CORRELATION.md) records the passive-correlation contract. Run only the applicable procedures under the repository's build and PTY approval rules; retain their receipts with the task evidence.
