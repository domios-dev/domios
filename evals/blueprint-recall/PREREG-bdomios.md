# PREREG: B-domios gate B on the real Domios recall path (attempt B-domios-1)

Committed before the first `--grid` run. Nothing below changes after this commit; deviations found later are reported, not patched in.

## Embedder

This attempt uses the current global mem embedder only: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (`codeterm-mem/src/embeddings.rs`, `FLOAT[384]`), reached solely through codeterm-mem's global path (`GlobalEmbedder` -> `embeddings::embed` / `embeddings::query_embed` -> `embedding_worker`). No second embedder exists. Domios's L12 path truncates at 512 tokenizer tokens, not sentence-transformers' 128; the agent and worker intents are short either way. A build on another global model measures that model with no harness change.

## Data

- **Corpus** (`corpus/`, 70 documents): E2's `poc/corpus` ported to v1. 68 v1 files are verbatim except that the PoC-only top-level `intent:` and `anchors:` lines were removed from 6 files (dev-run-health, dev-run-health-st, plan-review-gate, plan-review-gate-st, release-preflight, release-preflight-st), because Domios's `Document` refuses unknown fields. The two health-triage v2 files were hand-ported to their closest v1 pipeline (http probe, a `python3 -c` grading command standing in for the code step, an `ask` triage, `result: notify`); v1 pipelines have no escalate step. Deviation, recorded.
- **Gold** (`gold.json`): E2's `eval/retrieval/gold.json`, unchanged. A query about original O has gold = families[O] (O, O-st, O-sem).
- **Selection pool**: already-seen E2 set (a) 60 queries, set (b) 38, and E2b set b2 31 (`queries/`): 129 queries. b3 is not read before `config.frozen.json` is committed; b4 is never read.

## Simulated save-time inputs (cached by document hash, committed)

Generated by `blueprint_recall_eval --generate`, before this PREREG, from pipeline files only. No session saw a query, story, gold label, b2, b3 or b4.

- **Agent intents**: one fresh headless session per document, `~/.local/bin/claude -p --model opus --effort high --output-format json --tools "" --strict-mcp-config`, environment minus every `CODETERM_*`, empty temp cwd. The prompt is `INTENT_PROMPT` in `evals/blueprint-recall/runner/generate.rs` with the corpus file substituted, recorded verbatim in `save-inputs/intents.json`. It mirrors BLUEPRINTS.md: 3-5 differently worded `--when` intents. Raw session JSON: `save-inputs/sessions/<doc>.intents.json`.
- **Worker enrichment**: the product task, `enrichment_task(stored YAML, step gists)` from `blueprint_library/enrichment.rs` over the prompt `src-tauri/prompts/blueprint_enrichment.md`, exactly as the save path hands it to the enricher, run once per document with `--model claude-haiku-4-5-20251001` (the configured `memory.worker_model`) and the same flags. A report the product parser refuses leaves that document `enrichment pending` in every arm.

## Ingestion (temp store, no daemon)

`MemManager::open_offline` on a temp directory; each document goes through `save_blueprint_without_merge` (product qualification and abstraction, semantic canon, WL h=3 signature, document hash) and `index_blueprint` (one 384-dim vector per agent intent plus the canon vector), then `complete_blueprint_enrichment` with the cached report (product parser, provenance and worker vectors). Deviation: the product save merges a structurally identical document into an existing entry; E2 gold counts structural twins as separate documents, so the harness stores every corpus document as its own entry. Area `blueprints:eval`.

The product save path refuses one corpus document: distractor `dx-log-rotate` (`unsafe_template`: its templated `run` keeps a literal `/tmp/...` path, which the keep safety check rejects). A real keep would refuse it too, so the library holds 69 documents; it is in no recall family, and dedupe pairs touching it are dropped and their count reported.

## Metric

recall@k = |gold ∩ top-k| / min(k, |gold|), k = 1, 3, 5, averaged over queries; pooled and per set.

## Grid (at most 12 configs, all with enrichment on, no rerank, rrf_k 60, list depth 50, no structure list)

Weights are intent / worker intent / summary / canon / lexical. "pool" scores max-sim over agent and worker intents in one list.

| config | fusion | pool | weights |
|---|---|---|---|
| C1 | RRF | no | 1/1/1/1/1 |
| C2 | RRF | no | 1/1/1/1/0 |
| C3 | RRF | no | 1/1/0/0/0 |
| C4 | RRF | yes | 1/-/0/0/0 |
| C5 | RRF | yes | 1/-/1/1/0 |
| C6 | RRF | yes | 2/-/1/1/0 |
| C7 | RRF | yes | 2/-/1/1/0.5 |
| C8 | score | yes | 1/-/0/0/0 |
| C9 | score | yes | 1/-/0.5/0.5/0 |
| C10 | score | yes | 1/-/0.3/0.3/0.2 |
| C11 | score | no | 1/1/0.5/0.5/0 |
| C12 | score | yes | 1/-/1/1/0 |

"score" sums weighted cosines (lexical normalized by the best BM25 score). WL structure is kept out of intent recall (H-fuse); it fuses only when a draft is supplied, which no query set here does.

**Selection key**: highest pooled recall@5 on the selection pool, then pooled recall@3, then the lower config index. The winner is C*. `--grid` writes `grid.json`; `--freeze` writes `config.frozen.json` from it, and both are committed before any b3 file enters the worktree.

## Arms on b3 (one `--confirm --set b3` run)

- **Gate arm**: C* with enrichment, without rerank. **Gate B: pooled recall@5 >= 0.80 on b3.** Also reported per original and for B2's pre-registered starved originals (read from B2's manifest) separately.
- **Degraded arm**: C* with enrichment off (canon + agent intents only), the "enrichment pending" floor.
- **Rerank arm**: C* + rerank. The Supporter contract (`codeterm-supporter/src/rerank.rs`: `selection`, top 10, and `skip_reason`) is replicated verbatim in the harness because codeterm-supporter depends on codeterm-mem. No Supporter adapter is configured, so `memory.worker_model` (claude-haiku-4-5-20251001) is the labelled stand-in, prompted with the product `mem_rerank.md` over neutral labels b1..b10 (name, note, intents, enrichment summary). An unparsed or failed call keeps the fused order and is logged.
- **Dedupe**: verdict rules as SPEC section 6 (exact = equal document hash; structural twin = equal WL hash; near and semantic twin thresholds on S_struct, canon cosine and best agent-intent cosine). Thresholds are calibrated once on E2's 70 dev pairs (E2's grid and objective: dev accuracy, then fewest exact/structural verdicts on distinct pairs, then L1 distance to 0.80/0.90/0.85), frozen with C*, and reported on E2's 70 test pairs: informational against G4's 0.85, with the count of exact/structural verdicts on distinct pairs.

## Guards

`--confirm` refuses unless PREREG-bdomios.md and config.frozen.json are committed and unmodified, `results-<set>.json` neither exists nor appears in git history, and the sha256 of the queries file is recorded in the manifest. It writes `results-<set>.json`. `--posthoc` never writes a `results-*.json`. `--report` regenerates every table from `grid.json` and `results-*.json`.

## After the freeze

The product default `RecallConfig` is set to C* in a separate commit; the frozen file stays the harness's source of truth. A gate B FAIL is reported as measured; the pre-approved global embedder evaluation (B-emb-eval) then uses this harness unchanged.
