What to do about it

Reports run wide. A report's p95 is fifteen times its median, so some workers are pasting whole files into reports instead of naming them.

Heartbeats outnumber work. 366 heartbeats against 148 reports means the crew spends more turns announcing itself than delivering.

Read from kpi_events. Token counts exist only on token_usage rows, so they are never folded into a byte total; on those rows bytes holds input + output tokens, which is why the table labels them tok. compaction rows carry no tokens and zero bytes, so their size columns stay blank rather than reading zero. Rows with a null plan id are the "charged to no plan" bucket, not an error. There is no price table anywhere in this product, so nothing here is shown in money.
