Every state the view can be in

Three rules decide the copy. A figure that was measured is shown, including a real 0. A figure that was never recorded is a dash or a hatched bar with a reason, never a 0. A bucket that exists but has no name (no model reported, no plan) is a visible row, never folded into its neighbours. The header, scope line, filters and footer from the main frame stay in place in every state below.

This is the whole Claude account, not haiku. Allowance isn't reported per model, so the model filter only chooses which account to show.

A provider with no snapshot shows one line, “Codex hasn't reported allowance”, never an empty gauge. Past the provider's telemetry age the reading says “may be out of date”.

12 · Loading and refreshing DeferredLoader: nothing for 200ms, then placeholders

A first open shows placeholders only if the read takes longer than 200ms. Changing a filter or refreshing keeps the current figures in place and updates “as of”, with no flash. Reduced motion turns the placeholder shimmer off.
