The Analytics entry in the titlebar

A new tray button sits immediately left of Plugins and uses the same UI_TRAY_BTN (28 × 28, 6px radius, muted until hovered) and a lucide chart-column glyph at 14px with a 1.8 stroke, so it reads as one family with the bell and the puzzle piece. It is the only tray button with an open state, because it opens a main view.

Order, left to right: notifications · Analytics · Plugins · keep awake · divider · settings. The settings and keep-awake glyphs here are stand-ins for the existing icons, which don't change.

The four states, drawn at 3×
Rest · --ct-muted glyph, no fill
Hover · --ct-hover fill, --ct-fg glyph, native title “Analytics”
Keyboard focus · 2px --ct-accent ring inside the button, only on focus-visible
Open · --ct-active fill plus a 2px accent underline, aria-current="page"; shape carries it, not colour alone
With pinned plugins · Analytics stays outside the pill

The pill holds plugins the user pinned. Analytics is a fixed core entry and isn't pinnable, so it sits before the pill rather than inside it, and pinning or unpinning never moves it.

Web · 390px · Analytics open

At 390px the logo and name are already hidden (below 430px) and the tray is shrink-0, so it keeps all six controls: 5 × 28px + 9.5px divider + 4 × 2px gaps + 4px padding ≈ 162px of 390. The embedded toast container is what gives way, never a tray button. Each tray button stays 28 × 28 on narrow web like its neighbours; bringing the whole tray to 44px targets is a separate tray-wide change and is not part of this entry.

Behaviour

AspectDecision
PlacementIn Titlebar.tsx's tray, rendered before ExtensionsTray; on every platform and both themes.
Identitydata-testid="titlebar-analytics", aria-label="Analytics", title="Analytics". No text label at any width, matching Plugins.
ClickToggles the analytics main view: closed → open; open → back to the workspace. Opening closes Settings, Memory, Mesh or Plugins, as those views already do to each other.
ScopeMachine-wide. It is a main view like Plugins, not a tab-owned plugin view, so switching tabs or workspaces doesn't close it; focusing a tab does return to the workspace, as for the other main views.
KeyboardTab order bell → Analytics → Plugins. Enter or Space toggles. Escape inside the view returns to the workspace and puts focus back on the button.
VisibilityShown while the core analytics plugin is enabled, which it is by default. If the user disables the plugin, the button goes away; it never opens an empty or broken view.
Recording offThe button stays. The view explains that recording is off and names kpi.enabled; the button never carries a badge or a warning dot.
