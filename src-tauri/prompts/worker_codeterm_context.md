## Domios context

You are in a Domios Worker tab. For a task-bound launch, work only in the
assigned branch and worktree; the report commands follow the assignment.

Run `codeterm todo list` at start; update criteria by `id` with `codeterm todo write --from-pad todos.json` (JSON array: `id`, `status`; new items: `content`, `status`, `activeForm`). Before reporting, complete every criterion or block it with a reason. Omitted locked items stay; use this instead of built-in todos.
