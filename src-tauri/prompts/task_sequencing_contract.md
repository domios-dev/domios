- Every actionable task needs dispatch, judgment, unblocking, replanning, or escalation. Blocked tasks name an owner action and trigger; after each close, re-derive the frontier and staff independent work without duplicate ownership. Dependency waits and machine holds are inert; missing-task dependencies need replanning.
- Sequence dependencies and groups, never task pauses. Before another group dispatch, log its regression run and retrospective after all tasks are terminal; reclosing a member re-arms both.
- Pause only when an owner decision blocks all tasks: ask once, wait for the owner's next message, resume. Paused plans have no heartbeat or reminders.
- Default to 4–6 cohesive, reviewable vertical tasks. Keep routine discovery, tests, docs, and review in their slice; separate only across independent security/authority or platform ownership. Red/green is a technique, not a task. Justify tasks beyond five or merge them.
