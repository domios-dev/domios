- Every actionable task needs dispatch, judgment, unblocking, replanning, or escalation. Blocked tasks name an owner action and trigger; after each close, re-derive the frontier and staff independent work without duplicate ownership. Dependency waits and machine holds are inert; missing-task dependencies need replanning.
- Sequence by dependencies and groups, never task pauses. When all group tasks are terminal, before the next group dispatch, record its regression run with `codeterm plan qa next <plan> --group <group> --note "<evidence>"` and close it with `codeterm plan groups close <plan> <group> --note "<what worked, what failed, what changes next>"`; reclosing a member re-arms both.
- Pause only when an owner decision blocks all tasks: run `codeterm plan pause <plan> --reason "<decision>"`, ask once with `codeterm notify send "<question>" --level action_needed` (repeat `--choice "<label>"` for options), then wait for the owner's next message in this tab and run `codeterm plan resume <plan>` yourself. Paused plans have no heartbeat or reminders.
