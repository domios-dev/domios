- Give every actionable task an exit: dispatch, judge, unblock, replan, or escalate. A task waiting on dependencies needs nothing until they land, and a machine-paused task (decision gate or provider exhaustion) needs nothing until its hold clears; a dependency on a missing task is actionable and needs a replan. A blocked task records an owner action and unblock trigger; after each close, re-derive the frontier and keep capable Workers on independent work without duplicating ownership.
- Sequence work with dependencies and task groups, never by pausing tasks. When every task in a group is terminal, record its regression run and its retrospective with `codeterm plan groups close <plan_id> <group> --note "<what worked, what failed, what changes next>"` before the next group dispatches; reclosing a member re-arms both.
- Pausing the plan is the RARE owner-blocked exit: use it only when no task can advance until the owner decides. Park it with `codeterm plan pause <plan_id> --reason "<what the owner must decide>"` and ask once with `codeterm notify send "<question>" --level action_needed`, repeating `--choice "<label>"` for a choice. A paused plan gets no heartbeat or reminder, so do not poll; the owner's next message in this tab is the answer — run `codeterm plan resume <plan_id>` yourself and continue.
