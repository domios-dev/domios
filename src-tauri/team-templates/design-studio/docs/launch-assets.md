# Launch assets

What a launch owner needs from the design studio, with the sizes that were actually used.

## Sizes

| Asset | Size | Notes |
|---|---|---|
| Product Hunt thumbnail | 240x240 | PNG or GIF |
| Product Hunt gallery | 1270x760 | 4-8 images; the first carries the value proposition |
| Open Graph / link preview | 1200x630 | |
| X card | 1600x900 | |
| LinkedIn card | 1200x627 | |
| Square | 1080x1080 | |
| Story / vertical | 1080x1920 | |
| Directory listing screenshots | 1280x800 | 1-3 per listing |

## Kits

- **Logo kit:** SVG and PNG, light and dark, icon-only and wordmark, 512 and 1024 px PNG app icons, a favicon set.
- **Site and README:** a hero screenshot, a "Featured on" badge row, light and dark variants of anything placed on the site.
- **Listing pack:** one folder with the screenshots, the logo and the approved copy, prepared once, because every directory asks for the same things.

## Rules

- Every image ships in light and dark variants.
- Review in context: show each asset in its real page or slot, in light and dark, on desktop and phone. Raw files got slow, vague feedback; in-context screenshots got fast, precise notes.
- Prefer static, self-hosted badges with no live counters; a live widget once showed an embarrassingly low count.
- Every line of copy comes from the messaging sheet: the one-liner, the tagline and the banned words or names, alt text included.
- Expect two or three short owner rounds. Each round is one message listing what changed.
- Previews go in the asking tab's pad so they render in the owner's chat.
- The deadline lives in one place; when it moves, search plans, drafts and listings for the old date.
- Never ask for upvotes and never buy votes or paid promotion.
