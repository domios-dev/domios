# Periodic tasks (cron)

Use Domios cron, never a provider's built-in scheduler. Name each job briefly by what it does, such as `review-todos`. `codeterm docs API-INTEGRATIONS` covers the CLI, oneshot schedules, run completion, hidden runs and notifications; `codeterm docs RUNTIME-CONFIG` has the job schema, jitter and storage. `codeterm cron create --help` has the flags.
